## #1695 審査で落ちる所と対策

| ガイドライン | 対策 |
|---|---|
| 2.1 Google が WebView でのログインを断る | ログインだけ外のブラウザで済ませ、torecanavi:// で戻して同じログインを WebView に入れる。受け渡しは1回限りの code と、アプリの中の verifier の指紋で照合する |
| 4.8 メールを隠せるログインが要る | Appleでサインイン。**メールを共有した人は Google と同じアカウント**（同期ID＝メール・email_verified のときだけ）。メールを非公開にした人は apple:&lt;sub&gt; の別アカウント |
| 5.1.1(v) アプリ内でアカウント削除 | マイページの「アカウントを削除」。名前に同期キーを含む鍵を SCAN で全部消し、購読・LINE・集合の分も片付ける。Pro が続いている人は解約が先。セッションでしか消せない |
| 5.1.2 追跡 | アプリの中では広告を読まない |

- アプリの中では「ホーム画面に追加」の案内を出さない。
- アイコンは既存の 1024px のマーク（角丸なし）。起動画面・torecanavi:// の登録・暗号の申告・プッシュの権限は `ios-app/scripts/prepare-ios.sh`。
- 試験: 画面の試験を全部1回。4216件が緑。今回で増えた赤2件（canonical・login-choice）は直し、残りは main と同じ赤。新しい試験6件が緑。next build 成功。
