## 2. 見つけた穴（⑱・マージ済みの分）

**ブックオフJR蒲田駅東口店（締切 09-09）の本文はこうです。**

```
拡張パック 『30th CELEBRATION』
デッキセット『エーフィ・ブラッキー』
```

**2商品を募集している回**です。ところが辞書が当たったのは 拡張パック だけでした。後者の公式表記は「30th CELEBRATION プレミアムデッキセット エーフィ・ブラッキー」で、本文の書き方のほうが短いので当たりません。**「1商品しか書いていない」と読み違え、片方の名前だけを付けて配るところでした。**

⑱ の決まり（本文に公式の商品名が**1つだけ**なら採る）は正しいのですが、**「1つだけ」の数え方が公式表記の全体一致に頼っていた**のが穴です。

### 直し方

`another_product_hinted()` を足しました。**当てるためではなく、決めないための材料**として使います。

```
同じ弾の別商品の、弾名を除いた語（「プレミアムデッキセット」「エーフィブラッキー」）が
本文にあれば、**決めない**
```

短い書き方で別商品に**当てはしません**（短い名前から商品を決めるのは判断②⑦に反する）。**止めるだけ**です。⑳ の `fold_blocked` と同じ向きの道具です。

### 直した結果（実測）

| | 関門なし（いまの main） | 関門あり |
|---|---:|---:|
| 本文から商品が決まる候補 | 242 | **202** |
| 関門が開く回 | 3 | **2** |

止まった 40 件は、**全部が実際に2商品以上の回**でした。内訳は「拡張パック と プレミアムデッキセット の並び」が 38 件、残り2件も目視で確かめています。

```
トレカノ十和田元町店         本文に 拡張パック と プレミアムデッキセット の両方
ポケモンセンターオンライン   本文に BOX / カードセット各種 / FUTURISTIC BOX の3つ
```

全件は根拠データにあります。

## 7. 見つけた別の穴（この PR には入れていません）

metrics から回ってきた「遊戯王『グロリアス・ヴィクターズ BOX』が M2 に無い」を調べたところ、**M2 には載っていました**（`yugioh:dbgv`「デッキビルドパック グロリアス・ヴィクターズ」）。**照合の穴**です。

```
resolve("グロリアス・ヴィクターズ")       → set_only（弾まで当たる）
resolve("グロリアス・ヴィクターズ BOX")   → unknown  ← 末尾の BOX が壊している
```

公式の弾名のほうが長い（「デッキビルドパック」が付く）ので、短い名前用の逆向きの照合に落ちるのですが、`box` が付いているせいでそれにも当たりません。`sale_unit_of()` も裸の BOX を販売単位として拾いません（`1BOX` のような数量つきだけを見る作りです）。

**直しは別 PR にします。**「当たらなかったときだけ末尾の裸の BOX を外して引き直す」で、結果は **set_only どまり**（BOX という語から形は決めない・判断②）。公式名の一部としての BOX（「30th CELEBRATION FUTURISTIC BOX」など）は壊れないことを実測で確かめてあります。影の欄が何件動くかを測ってから出します。
