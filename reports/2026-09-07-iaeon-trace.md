# 報告

## 1. iAEON はどこで消えるか: **人の確認（review）で止まり、締切が過ぎた**

候補台帳に **10行**あります。**10行すべてが `review_status: pending` かつ
`lifecycle_status: expired`**。

| 段 | iAEON |
| --- | --- |
| サイトを巡回で開いているか | **開いている**（`linked_page_cache.json` に18箇所） |
| 記事を拾ったか | **拾えている**（`aeon-kyushu.info/customer/information/…` が根拠に入っている） |
| 抽選と判定されたか | **されている**（候補台帳に10行・商品も締切も入っている） |
| 抜粋・根拠 | **ある**（`official_unverified` の公式根拠つきの行が6本） |
| 刻印・配布行 | **無い** |
| **止まっている段** | **人の確認（`review_status: pending`）。その間に締切が過ぎて `expired`** |

例（そのまま抜粋）:

```
イオン九州iaeonアプリ｜pokemon｜ポケモンカード30thcelebration
  review=pending  lifecycle=expired  apply_end=2026-08-30T23:59
  url_status=found  reason=has_application
  evidence=[('web','https://aeon-kyushu.info/customer/information/arch','official_unverified'),
            ('web','https://cardchusen.com/pokeka','unofficial')]

イオン九州限定iaeonアプリ｜yugioh｜遊戯王OCG…
  review=pending  lifecycle=expired  apply_end=2026-09-06
  url_status=found  reason=has_application
  evidence=[('web','https://aeon-kyushu.info/…','official_unverified'),
            ('x','https://x.com/yugioyoyaku/status/…','unofficial')]
```

**取得の問題ではありません。**公式サイトの記事を拾い、応募URLまで取れていて、
**人が確認していないあいだに締切が過ぎています**。

### あわせて見つけたこと（`store_keys` の書き方が実物と合っていない）

候補側の店名は **4つに割れています**。

```
イオン九州 ／ イオン九州iAEONアプリ ／ イオン九州限定iAEONアプリ ／ イオン北海道iAEONアプリ
```

いっぽう `store_keys` は **`イオン九州 (iAEON)`**。正規化しても
`イオン九州(iaeon)` ≠ `イオン九州` で**一致しません**。

**つまり iAEON は、仮に人が確認して配布行になっても、いまの正本の数え方では
数えられません。**前回「完全一致は社を落としていない」と報告しましたが、それは
**いま存在する行について**であって、**`store_keys` が実物の形で書かれていない社が
ある**という別の問題は残ります。1社ぶんですが、同じ形が他にもある可能性があります。

## 4. (b) 「晴れる屋2各店（店舗）」を本部として数える件

**除きません。本部の行として数えるのが正しい**と考えます。

* §3-1-1-c が排除するのは「**支店だけの抽選**」です。「各店（店舗）」は
  **チェーン全体の告知**であって、支店ではありません
* `store_keys` は**名簿の持ち主が意図して3つ登録**しています
  （`晴れる屋2` ／ `晴れる屋2 通販` ／ `晴れる屋2各店（店舗）`）。
  これは「この3つの名前で来た行は本部として扱う」という宣言です
* **`store_keys` に「各店」「全店」を含む鍵は 82鍵中14鍵**あります
  （`イエローサブマリン各店` `フルコンプ各店` `竜のしっぽ各店` `イトーヨーカドー各店`
  `ドラゴンスター各店` `シーガル各店` `ビックカメラ各店` …）。
  **これを支店とみなして除くと、14鍵ぶんが一斉に落ちます。**
  受付中の8社のうち GIRAFULL・フルコンプ・ドラゴンスター・晴れる屋2 が該当し、
  **8社が4社になります**（15行→7行）

除くべきは「`◯◯店` という**個別の支店名**の行」であって、「各店」ではありません。
api-customer の数（14鍵）と突き合わせてください。
