# 抽選情報のスマホ画面をモックの形にそろえた（PR #1501）

日付: 2026-09-09 / セッション: uidesign

## 受けた指示（本人・チャット）

> これの通りにスマホ画面を作成したかったんだけど、ちょっと違くなってしまった。
> この画像の通りにできる？

添付は 2026-09-09 19:23 のスクリーンショット（390px 幅・抽選情報タブ）。

## 先にやったこと: 「いまどうなっているか」を実測した

モックと突き合わせる相手が要る。**手元の作業ツリーは読まない**決まりなので、
`origin/main`（`f15ada27`）から使い捨ての作業木を切って、そこで
`next build` → `next start -p 3543` → **CDP で 390px の実ビューポート**を作って撮った。

- ヘッドレス Chrome の `--window-size` は 500px 未満を作れないので、
  `Emulation.setDeviceMetricsOverride {width:390}` を使う
- 最初に撮ったのは**古い main**（`f35b74fe`）で、モックとまるで別物だった。
  `origin/main` はその時点で **20コミット先**にいて、#1499 / #1500（`codex/chain-date-table`・
  `codex/nationwide-axis`）で今回のモックに寄せる作業が**すでに入っていた**。
  「違う」の中身は**作り直しではなく、残りのずれ**だった。

この確認をしないと、既にある実装をもう一度作るところだった。

## 直したずれ（8か所）

| モックの形 | 直す前 | 直したあと |
|---|---|---|
| 見出し「抽選情報」と 大手チェーン／全国店舗 が**1行** | 枠付きカードで2段・切り替えが幅いっぱい | 1行。選んでいる方は**塗らずに縁取る** |
| ゲームの札が小さく、選択中は**白い縁** | 大きく、選択中は緑 | 小さく、白い縁 |
| すべて／BOX別／店舗別 が**幅いっぱいの3等分** | 左寄せの丸い札（横スクロール） | 3等分の切り替え |
| BOX の帯が**正方形**・発売日の判子なし | 縦長・日付の判子つき | 正方形・判子なし（**大手チェーンだけ**） |
| 応募条件カードが**角丸＋📋** | 四角・左に赤い縦線 | 角丸・📋・線の色なし |
| **商品名＋件数＋グリッド／まとめ表** | 「大手チェーンの抽選まとめ」＋赤い丸「55チェーン」 | 見出しを新設 |
| 締切日の帯が**塗りつぶし** | 薄い地＋左の縦線＋「1件」 | 塗りつぶし・件数は出さない |
| 行が **応募／受取が1行ずつ＋右に応募ボタン** | 応募方法・受け取りが2列の表＋幅いっぱいの「詳細」 | モックの並び |

### 中で1つだけ「見た目でない」変更をした

**見せ方（グリッド／まとめ表）をタブ（すべて／BOX別／店舗別）から切り離した。**
それまでは `店舗別＝グリッド／それ以外＝まとめ表` と連動していて、モックのように
「BOX別を見ながらグリッドに切り替える」ができなかった。既定は今までと同じ
（店舗別→グリッド／それ以外→まとめ表）で、押されたときだけその選択を使う。
タブを変えたら既定へ戻す（前のタブで選んだ見せ方を持ち越すと、何を押して
変わったのか分からなくなる）。

### 「詳細」を消しきらなかった理由

モックの行にあるボタンは「応募する」だけなので、スマホでは「詳細」を隠した。
ただし**応募ボタンが無い行では出す**。手元のデータでは応募URLを持つ回が
**0件**で、両方消すと**その行だけ押せる所が本文しか無くなる**（実際に撮って気づいた）。

## わざと合わせなかったところ（2件）

1. **締切日の帯の「年」。** モックは `9/12（土）`、実装は `2026/9/12（土）`。
   日付は全部年月日を付ける決まり（2026-08-06 本人指定・「同じ1行の中で書き方が
   食い違わないように」）があるので残した。**落としてよければ1行で直せる。**
2. **画面下の丸い ↓ ボタン。** モックにあるが、何をするものか決められなかったので
   入れていない（押した先を決め打ちにすると、後から別物になる）。
