# 詳細ポップアップの応募帯・管理画面・X投稿のポスターを、新しい配色とロゴへそろえた

2026-09-18。#1618（紺と青の配色）のあとに本人から出た画面の指示をまとめて進めた報告。
PRは2本で、**どちらもマージ待ち**（本人の「マージして」を待つ）。

## 1. PR #1624 詳細ポップアップ（ブランチ feat/sheet-sticky-actions）

* 詳細ポップアップの下端に**帯を固定**：左に「フォロー」、右に「応募する」
  * 文言「この抽選に応募する」は**普通の応募ページのときだけ**。X投稿・アプリ・店頭が応募先の回で
    「応募する」と書くと嘘になるので、`dockApplyLabel` で出し分けた
* 応募条件をひとつの枠にまとめた
* サイドバーの一言「トレカ抽選、もう見落とさない。」を外した（本人「外していいです」）
* サイドバーのいまの項目を青の面に（`#2c67dd`・白文字 5.13:1）
* 「この店舗を一覧から隠す」を赤に。リンクは「{店名}の店舗ページを確認する →」
* **PCでは横長の2列**（左＝店の情報／右＝X告知のプレビュー）。プレビューが無い店は1列のまま

## 2. PR #1627 管理画面・ポスター・OGP画像（ブランチ feat/admin-poster-brand）

### 管理画面
* 見出しを絵文字の「🛠 管理画面」から、公開画面と同じロゴ＋「管理画面」の札へ
* 紺・ダークでは左メニューが**白い箱に淡い字で読めなかった**。項目を帯へ直接乗せ、いまの項目は公開画面と同じ青に

### X投稿のポスター（/shot/golden ほか）
* 旧ロゴの黄 `#fdc903`・茶 `#241915` → 見出し・表の頭・足元は帯の紺、日付・札・フォローは青、地は無彩色
* ロゴは新しい1枚を白のまま出す
* **見つけて直した不具合**：起動の幕が消えきる前に撮ると、ロゴが**透かしで表の真ん中に写っていた**。
  撮影ページでは幕を出さないようにした

### ロゴ・画像
* OGP画像 `og.png`（XやLINEにURLを貼ったときのカード）が**黄の地＋旧ロゴのまま**だった → 紺のグラデーション＋新アイコンで作り直し（`build_og_image.py` を更新）
* 参照は無いがURLで開ける旧ロゴ2枚（`/brand/logo.png`・`/icon-512-round.png`）も新しい意匠へ
* 当選を記録したときの演出（稲妻・紙吹雪・光）も黄から青・紺・金へ
