```
route_posts:kv 2331 ／ route_posts:render 0
accounts 440 ／ opened 440 ／ misses 0 ／ stopped_early 0

```

- **`route:none` は0件。** 「開けたのに何も取れなかった」店はありません

  （`route_posts:render 0`）。runner は依然 Cloudflare に塞がれているためです。
  **どの店かは特定できません**——経路は店ごとには記録しておらず、数だけです

  残り2枠（14:00 / 20:00）で回ります

## 5. 測り方と、途中の誤り

- 対象は run **34008887469** が押したコミット **361a34b7**。
  その1つ前との差分で「この回で新しく足された公式Xの根拠」を数えました
- 台帳は `source` 欄ではなく `evidence[*].source_medium == "x"` で持っているので、
  そちらで絞っています
- チェーンへの寄せは `web/public/data/golden_chains.json` の `store_keys` を
  正規化して、完全一致 → 前方一致（3文字以上）の順で当てています。
  **チェーンの鍵は本部名、公式Xの登録は支店名**なので、完全一致だけでは拾えません
