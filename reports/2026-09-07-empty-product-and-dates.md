```

## 359件の正体は「弾名の当て方が全体一致すぎる」

弾の正本は**接頭辞ごと**登録されています。

```
台帳の弾名   「ブースターパック BRIGHTNESS OF HOPE [FB11]」
投稿の書き方  「DBFW BRIGHTNESS OF HOPE 【FB11】 を抽選販売とさせていただきます」
             → **全体が本文に出ないので当たらない**

台帳の弾名   「ブースターパック 天元突破グレンラガン」
投稿の書き方  「ユニオンアリーナ 【天元突破グレンラガン】は 予約販売分のみ」  → 当たらない

当たった例   「UNION ARENA ブースターパック BLEACH 千年血戦篇 Vol.3【EX15BT】」
             → 本文が**丸ごと**書いていたので当たった
```

## 芯（接頭辞と型番を外した形）で当てたら、いくつ埋まるか

```
435件のうち   **54件**が芯で当たる
             381件は**それでも当たらない**
```

**54件は「弾名の当て方」を直せば埋まります。** ただし**誤爆もあります**——
「進撃の巨人3」（Switch のゲーム）や、ガラガラ抽選の景品「ワンピース 決戦の刻」まで
拾ってしまいました。**そのまま入れると別の問題になります。**

残る381件は、**投稿が商品名を書いていません**。

```
「【トレカ予約情報】予約情報を更新いたしました」
「ワンピースカードゲーム新作商品の抽選予約の受付を開始いたします」

> **まとめると、主因は「本文にそもそも商品名が書かれていない」です。**

> 弾名の当て方を直せば **54件**。合わせても83件で、**445回の一部**です。
