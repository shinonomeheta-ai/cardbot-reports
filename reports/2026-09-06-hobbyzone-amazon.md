## ③ 経路を作れるか → **作れます。実測しました**

Amazon の「招待リクエスト」は、**商品ページと検索結果に静かに現れる**形でした。

```
検索        amazon.co.jp/s?k=ポケモンカード 30th CELEBRATION
実ブラウザ   普通に開く（ボット検査なし・本文14,051字）
結果        54件中 13件に「招待された方のみご購入いただけます」
```

**13件の中身が、正解表とほぼ一致します。**

```
拡張パック 30th CELEBRATION BOX                     ← 正解表の「30th BOX」
30th CELEBRATION プレミアムデッキセット エーフィ・ブラッキー  ← 「プレミアムデッキ」
30th CELEBRATION カードセット  フシギダネ／サルノリ／チコリータ／
                             ツタージャ／ハリマロン／モクロー／
                             ニャオハ／キモリ  の 8種             ← 「カードセット9種」の8つ
ハイクラスパック MEGAドリームex BOX
拡張パック ストームエメラルダ BOX                       ← ここ3つが「常設」に当たる
拡張パック ムニキスゼロ BOX
```

**カードセットは9種のうち8種**でした。ナエトル・ヒコザル・ポッチャマだけ、
別の検索でも招待リクエストの出品が出ません（出るのは転売の出品だけ）。
**Amazon が出していないのか、検索に出ていないだけかは分かりません。**

### robots.txt（作る前に確かめました）

```
User-agent: *   /s も /dp も禁じていない
                （禁じているのは product-availability・rate-this-item などの個別パス）
User-agent: GPTBot   Disallow: /    ← 全面禁止
```

**検索と商品ページは、規約上は読める形**です。ただし
**GPTBot は全面禁止**なので、名乗り方には注意が要ります。

### 作るとしたらの形（案・実装していません）

```
1. 弾の正本（set_images）から検索語を作る
2. amazon.co.jp/s?k=<弾名> を実ブラウザ経路（render_text）で開く
3. 「招待された方のみご購入いただけます」を含む結果を拾う
4. 商品名 → product_master、URL は /dp/<ASIN>
5. monitoring: start_only なので締切は入れず「受付中・締切なし」で1行
```

**既存の「締切で配る」形とは合いません**が、画面側（`start_only` の「不定期受付」）は
**もう出来ています**。足りないのは収集だけです。
