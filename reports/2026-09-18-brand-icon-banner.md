# アイコンと起動の幕のバナーを差し替える（PR #1617）

本人指示 2026-09-18「ダークとダークじゃないアイコンとバナーをこれに変えられますか。
起動時のバナーです」。渡された2枚（正方のアイコンと TORECA NAVI の横組み）から作った。

## バナーは透過で持つ（2枚持たない）

渡された絵は**濃紺の地に白抜き**。そのまま置くと、明るい配色のときに
**黒い板**が画面の真ん中に出る。

そこで白のまま**透過**で切り出した（明度を α にする）。地は配色の地を
そのまま使い、色は CSS で決める。

    .boot-splash-logo { filter: brightness(0); }             明るい配色 → 黒
    [data-theme="dark"|"steel"|"boltnight"] → filter: none   暗い配色 → 白のまま

**「ダーク用」と「ダークでない用」の2枚は作らない。** 2枚に分けると、
片方だけ差し替えたときにずれる。絵は1枚、色は1か所。

実描画で4配色（ダーク／ボルト／クリーム／スチール）を目視した。どれも読める。

## 差し替えた範囲

| ファイル | 何に出るか | 作り方 |
| --- | --- | --- |
| `/brand/boot-wide.png` | 起動の幕**専用**（新規） | 白抜き・透過・高さ256 |
| `/icon-512.png` `/icon-192.png` | Android・PWA | 角丸の正方を切り出し |
| `/apple-touch-icon.png` | iOS | 180px |
| `/icon-512-maskable.png` | 切り抜かれる端末 | **角丸を焼き込まず**縁まで地を塗り、絵は安全圏（中央）へ |
| `/favicon-32.png` | タブ | 32pxでは字が読めないので**印だけ** |

画面の上の帯のロゴ（`/brand/logo-wide.png` ＝ 黄と黒の「トレカナビ」）は
**別物なので触っていない**。差し替えるかは別の判断。

## Service Worker の世代を上げた（v10 → v11）

アイコンは名前が変わらないので、世代を上げないと端末に**前の絵が残り続ける**
（`/box/` と `/logo/` をネット優先にしたのと同じ理由）。
