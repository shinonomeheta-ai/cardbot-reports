## ② EC一覧の巡回が押せずに落ちていた

### 実測

| 34107348106 | S1 8行（新規5） | 同 |
| 34069409550 | S1 4行（新規2） | 同 |

**5 run とも同じ理由。** 候補台帳は5つの経路が同時に足すので、行単位の rebase で
JSON を混ぜようとすればいつか必ず当たる。

#1329 が握り潰しを止めて赤にしたのは正しい（**消えるより止まるほうがよい**）。
ただし止まったままなので、**載らないことは直っていなかった**。

**押し直し（`data_push.py`）では直らない。** あれは push の**拒否**をやり直すもので、
rebase そのものが競合する場合は同じところで止まる。

### 直し方

`official-x-intake`（#1268）と `official-x-web-discovery`（2026-08-28）の型を部品に
した。控えは**台帳を書く前**に置き、押すときは最新 main へ `reset --hard` してから
`CL.upsert` / `LC.upsert` という**巡回本体と同じ入り口**へ通し直す。

**独自の統合規則は書いていない。** 台帳は「足すだけ・何も消さない」upsert を持って
いるので、同じ関数へ通せば、その間に他の経路が入れた変更（人の判定・AI の結果）を
踏み潰さない。ここで新しい merge を書けば、そこが新しいバグの置き場になる。

当て直しに失敗したら**押さない**。空のまま「変化なし」で緑に終わるのは、#1329 が
止めた握り潰しと同じ。控えは artifact に残す。

### 途中で見つけた自分の間違い

**試験が本物の `linked_page_cache.json` を書いた。**

    def load(path=PATH):   # linked_page_cache ← 既定値は import のときに決まる
    def load(path=None):   # candidate_ledger  ← path or PATH（差し替えが効く）

同じ見た目で挙動が違い、`LC.PATH` の差し替えでは実データを守れていなかった。
置き場は必ず引数で渡す形に直し、**本物の置き場の mtime が変わらないこと**を
検査に固定した。

## ③ 判定⑧（V5 の店 conflict）の中身

    母数 AIが店を比べられた 436回（confirmed 327 + conflict 109）

    （全 1,336 回に対しては 8.2%）

### 内訳

| 件数 | 何が起きているか | 例 |
| --- | --- | --- |
| **49** | **本文に店名が無い。** AI は `observed_store` を空のまま `conflict` と付けている | 「アカウント名のみのため店舗名は確定できない」 |
| 55 | 別の店名を観測した。ただし中身は**粒度の違い**が主 | 「川崎駅前」（正式名の短縮）／「ジョーシン」（支店名なしの全社告知）／「イトーヨーカドー各店舗」 |
| 5 | 観測した店名がアカウント名そのもの | 英字のアカウント名 |

**半分（54件）は「食い違い」ではなく「本文が名乗っていない」。** 公式Xの投稿が
アカウント名でしか名乗らないので、AI は正式名と突き合わせられず `conflict` を返す。

#1263 で見た「`conflict_status` は段で意味が変わる」と同じ型で、**語彙が「不一致」と
「未記載」を区別していない**。

### 配布への影響（実測）

`promote_candidate_decisions.新規で当てる欄` に `store` が入っており、`conflict` の
ときは AI の観測値を採る。**空の観測は採らない**（`ai_observed_empty`）ので 49件は
無害。残る 50種類の観測名のうち、配布行の店名として実在するのは **3種類だけ**。

    TSUTAYA Trading Card 平塚店   配布 1行   ← 正式名。問題なし
    チェルモサード                配布 1行   ← 正式名。問題なし
    エディオン                    配布 2行   ← **支店名の無いチェーン名**

つまり**いま配布へ実害が出ているのは2行**。仕組みとしては粗い名前が入り得るが、
規模は小さい。

### 費用（見積り）

Sonnet-5 の控え71本（requests 1,228・見積り $67.65）から:

    1応募回（a/b 2本） $0.1102

| | 内容 | 費用 | 効き |

| **A** | **読む側で分ける。** `observed_store` が空の `conflict` を「未記載」として扱う（プロンプトは変えない＝聞き直し無し） | **$0** | 49件が正しい意味になる。半分が片付く |
