## 2. `announce_type` を台帳へ（#1474）

### 2-1. 判定の規則（推測しない）

社に紐づく候補（`shadow_candidates.json`）の**根拠URL**だけを見ます。

| 見るもの | 条件 |
| --- | --- |
| 公式サイトの根拠 | URLのホストが `store_sites.json` の登録ホスト（サブドメイン可） |
| 公式Xの根拠 | `x.com/<handle>/status/…` で `<handle>` が `store_x_accounts.json` にある |

両方あれば `both`、片方だけならその経路、どちらも無ければ `unknown`。

```
both 16社 ／ official_site 16社 ／ official_x 12社 ／ unknown 11社
```

**`unknown` は「告知しない」ではありません。** 登録済みの口からの根拠を1本も
持っていない、という意味です。**口の登録漏れもここに入ります。**

実例が TCG shop193 です。公式Xは3口ありますが、登録名が
`TCGショップ１９３ 名駅椿店`（全角数字）・`TradingCardGameShop193秋葉原店` で
社へ寄らないため `unknown` になります。**この PR では直していません**（別名表の話）。

### 2-2. 朝の手集計との差（10社）

```

セブンネット      official_x → both          イトーヨーカドー  unknown → official_site

HMV&BOOKS online unknown → official_site     ヨドバシカメラ    official_x → both
```

## 4. 2枠続けて遅い原因: **1件あたりの応答が2倍になった。量は同じ**

### 実測

| 枠（JST） | run | 店 | 取れた投稿 | 所要 | 投稿1本あたり |
| --- | --- | ---: | ---: | ---: | ---: |
| 9/7 19:37 | 34110168765 | 1,438 | 7,303 | 1,511s | 0.207s |
| 9/7 20:21 | 34114404179 | 1,439 | 7,556 | 1,223s | 0.162s |
| **9/8 08:43** | 34168593460 | 1,440 | 7,520 | **2,412s** | **0.321s** |
| **9/8 12:41** | 34182024382 | 1,440 | 7,539 | **2,434s** | **0.323s** |

**店数も取れた投稿数も同じ**です（1,440店・約7,500本）。経路の内訳も同じで
`route:kv` 1,429〜1,437、`route:render` 3〜11、`route_posts:render` は**両日とも0**。
遅くなったのは**1本あたりの取得**だけで、**きっかり2倍**です。

段の内訳でも、遅いのは `Intake official X posts` の1段だけ（2,412s / 2,434s に対し、
他の段は合計20秒未満）。ログの空白時間もその中に収まっています。

### 原因（いちばん確からしいもの）

**`cdn.syndication.twimg.com/tweet-result` への1日の呼び出し数が増えたことに対する
緩やかな絞り込み**だと見ています。

```
9/7  部分1周×3 + 全店1周×2   ≒ 19,400本／日
9/8  全店1周×4               ≒ 30,100本／日   （+55%）
```

遅くなり始めたのが**4回運用に切り替えた最初の枠**（9/8 08:00）で、そこから
2枠続けて同じ 0.32s/本です。**429 は3件だけ**（タイムラインの経路で、これは以前と同数）
なので、はっきり撥ねられているのではなく**待たされている**形です。

**ここは断定ではありません。** 実測できたのは「量は同じで単価が2倍」「切り替えの
枠から始まった」の2つで、相手側の絞り込みそのものは見えていません。

### 段1へは戻していません

戻す条件（ブロックの兆し）に当たらないためです。

* **収穫は落ちていません**（7,520 / 7,539本・9/7 の 7,556本とほぼ同じ）
* `route_posts:render` は 0 のまま（読む役が塞がれていない）
* 42分は打ち切り（70分）の中に収まっている

**ただし余裕は減りました。** いまの倍率がもう一段進むと 70分に触ります。
16:00 と 20:00 の枠を見て、**3枠目・4枠目も 0.32s/本のままか、悪化するか**を測ります。
悪化するようなら段1（3回）へ戻します。
