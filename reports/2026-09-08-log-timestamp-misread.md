# 1. 何を間違えたか

直前の報告で、私はこう書きました。

> **種類A**は「押し直します」「12.6秒待ってから」と書いた**8.5ミリ秒後に終了コード1**
> （待っていない・`data_push.py` 618-625 付近）

**根拠になっていませんでした。取り下げます。**

そのステップのログはこう並んでいます。**5行とも同じミリ秒台**です。

```
10:34:41.4185516  ##[error]main へ保存できませんでした（**作り直した生成物をstageできなかった**）
10:34:41.4199766    local: 5583086293f0 ／ remote-before: 3ed2c9674f06 ／ remote-after: 4ddd17ab4994
10:34:41.4202476    retryable: true
10:34:41.4204391    push を押し直します（1回目・mainが先に進んでいて押せなかった）
10:34:41.4204949    12.6秒待ってから取り込み直します
10:34:41.4289908  ##[error]Process completed with exit code 1
```

**出力がブロックバッファされていて、終了時にまとめて吐かれています。** つまり
**タイムスタンプは「起きた時刻」ではなく「流れ出た時刻」**です。

```
commit  10:34:23.2480288
終了     10:34:41.4289908
        → **18.2秒ある**。12.6秒の待ちは入る余地がある
```

**押し直しは走っていたと見るのが自然です。** `data_push.push_with_retry` の `while True`
も、待ち → fetch → rebase → 影の作り直し → 関門 → 押し直し の順も、読み直したところ
壊れていません。
