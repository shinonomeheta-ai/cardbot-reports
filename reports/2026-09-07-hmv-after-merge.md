## 2. 揺れる赤の正体（#1447 を出しました）

`test_公開データの応募URLが減らない` が run ごとに赤くなったり緑になったりしていた件です。**PR 固有ではありませんでした。**

| コミット | 中身 | 結果 |
| --- | --- | --- |
| `eb6f0c24` | #1440 の土台・**PR のコードなし** | **赤** |
| `c5c50024` | 基準に使った main | 緑 |
| `8f4fc752` | いまの main | **赤** |

巡回でデータが入れ替わるたびに点いたり消えたりします。**PR のコードは無関係**でした。

### 原因

同じ店が2つの表記で配布データに残っています。

```
りらい(福島)                      source=human_review  締切 2026-09-15
カードゲームショップ りらい（福島）  source=ai_checked    締切 2026-09-15T23:59
```

応募先の X 投稿は**同一**（`status/2089626671578267806`）、県も同じ、商品名の違いは鉤括弧の有無だけです。合流は「同じ応募先URL」を根拠にこの2行を畳みますが、`store_identity` は `store_aliases.json` にこの別名が無いので**別の店**と読みます。試験はその食い違いを捕まえていました。

### 直し方

`store_aliases.json` に1本足しただけです。`_readme` の決まり「同一URLで同一店だと確認済みのものだけを入れる」を満たしています。

```json
"カードゲームショップ りらい（福島）": ["りらい(福島)"]
```

合流が「完全に同じ行を畳みました: 2 → 1件」と出るようになりました。**利用者に同じ抽選が二重に見えていた状態も直ります。**

試験: `test_url_candidate` 33件 OK、別名に触る9モジュール 309件 OK。

## 4. サイト経路42社の実測（本番と同じ関数で）

`一覧を開く → 記事リンク` をそのまま呼びました。これまでの「読めない13社」は、素の HTTP で叩いた数字でした。**本番は読めないときブラウザ描画へ落ちます**ので、実態は違いました。

**「機械で読めない公式サイト」は Joshin 1社だけ**です。403 を返していた あみあみ・トイザらス・イオンスタイル・ドラゴンスターは、描画経路では読めています。

ただし**測ったのは私の PC からです。** runner は別の IP なので同じとは限りません。runner での実測を走らせています（`ec-lottery-watch` の probe・書き込みなし・課金なし）。結果は次の報告に入れます。

### 読めるのにリンクが0本の社（14社）を中身で分けました

| 型 | 社 |
| --- | --- |
| 一覧が読めない | Joshin |
| 一覧に自ホストのリンクがほぼ無い | セブンネット・ドラゴンスター |
| **link の型が当たらない** | **イオンスタイル・TSUTAYA・お宝創庫・平和堂** |
| 型は当たるが抽選記事が無い | あみあみ・HMV・ヤマシロヤ・イエサブ・フルコンプ・ホビーゾーン |

型が当たらない4社は、ヤマダと同じ間違いです。実物と並べると:

```
TSUTAYA    型 /article/…\d+\.html   実物 /articles/book-comic-5452
お宝創庫    型 …(news|lottery|chusen)…  実物 /information/98776052/
平和堂     型 /news/…              実物 /info
```

**直した型を当てると 18本・13本・4本 に増えます。** ただし**そのどれも抽選記事ではありません**。関心語（抽選・ポケカ等）で絞ると 0本のままです。

つまり**型を直しても今日は行が増えません**。次にその社が抽選を出したときのための備えです。型の修正を出すかは判断をお願いします（データだけの小さな差分です）。

### いちばん大事な読み取り

一覧が読める41社のうち、**抽選記事が実際に載っているのは16社だけ**です。残りは読めていて、型も（直せば）当たって、**単に今その社が抽選をやっていない**か、一覧が抽選を載せる場所ではありません。

**サイト経路の材料不足は「読めない」ではなく「載っていない」です。** 公式サイトを読めるようにする作業からは、これ以上の収穫は大きくありません。
