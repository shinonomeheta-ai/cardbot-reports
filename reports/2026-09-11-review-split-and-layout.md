# 管理画面「データ確認・修正」を大項目で分けた（大手チェーン／支店／その他 × 人チェック）

2026-09-11 / PR #1521・#1522・#1524・#1525（すべて main へマージ済み）

## 1. 何を頼まれたか

本人の指示（原文）:

> データ確認・修正で出すものを分けたい。あと、データ確認・修正のレイアウトが汚すぎる
>
> 1（大手チェーン／支店）。そのうえで**大手チェーンはシステムチェックのみとシステム
> チェックを土台にした人チェックで明確にわける**。理由は人チェックでしばらく運用して
> システムチェックのものと差異がなくなってきたら**システムチェックのみに切り替えれる
> ようにするため**
>
> 管理画面 大項目で支店と大手チェーン分けて
>
> 店の区分を一段上のタブに

分ける相手は**店舗管理（マスタ）ではなく「データ確認・修正」の画面**。

## 2. 入れたもの

### 2-1. 大項目（左メニューの節）で分けた — #1524

`抽選データ確認` の下に節を3つ置いた。絞り込みの中ではなく**節そのもの**を分けたので、
画面を開いた時点で母数が分かれている。

| 節 | 出るもの |
| --- | --- |
| 大手チェーン | 台帳（`golden_chains.json`）の `store_keys` と**完全一致**する本部の回 |
| 支店 | チェーン名で始まるが本部ではない店の回 |
| その他 | 台帳に無い店の回 |

判定は `storeScope()` 1か所。**前方一致へ緩めない**（本部と支店が混ざると、Web受付の
本部と店頭の支店が同じ表に並んでしまう）。台帳が読めない時は「0件」と言わず**絞らない**。

### 2-2. 店の区分を一段上のタブへ — #1525

状態のタブ（未確認／確認済み…）より**上**に区分の帯を置いた。節で固定されている
ときは帯を出さない（同じことを2か所で言わない）。

### 2-3. チェックの担い手で分けた — #1521

大手チェーンの中を2つに割った。

* **システムチェックのみ** … 機械が入れたまま、人がまだ決着させていない回
* **人チェック済み** … 人が「そのままでOK／直してOK／掲載しない」を決めた回

下書き（`pending_review`）は**まだ人チェックではない**として機械側に置く。

### 2-4. 切り替えの目安を出した — #1521

本人の目的は「差異がなくなったらシステムチェックのみへ切り替える」こと。だから
**分けるだけでなく、差が数で見えるように**した。

```
一致率 ＝ そのままでOK ÷（人が確認した数 − 掲載しない）
```

「掲載しない」は母数から外す（出す/出さないの判断は、値の食い違いとは別の話）。
確認が0件のときに「一致100%」と言わないようにしてある。

### 2-5. レイアウト — #1522

* 応募方法／受取方法／条件／備考を**横いっぱいの帯**へ落とした
* 1行の高さ 778px → **442px**
* 表の中の横スクロールを解消（1028px → 1002px＝窓と同じ）

**切り替えの目安**

| | 人が確認 | そのままでOK | 直した | 掲載しない | 一致率 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 全体 | 328 | 0 | 211 | 117 | **0%** |

読み方: **いまは切り替えられない。** 人が見た回はすべて手が入っている（「そのままで
OK」が1件も無い）。この数字が上がってきたら、大手チェーンをシステムチェックのみで
回す判断ができる。

## 4. まとめ画像の「受付なし」が0社になっていた件 — PR #1527（CI待ち）

朝のまとめ画像（4:5）の `現在受付なし（50社）` が、**下に余白があるのに社名が1つも
出ず**「社名はサイトで一覧できます」だけになっていた。

原因は測り方。自動縮小が**紙と窓の高さ**を比べており、撮る窓の大きさが決まる前に
測った回は「ぜんぶはみ出している」と読む。減らすだけの繰り返しなので**0まで削れて
戻れない**。

直し方:

* 紙の高さを窓へ固定し、余りを受け持つのは「受付なし」の節だけにした
* 数を決める判断は**その節の中の箱からあふれたか**だけを見る（窓の大きさを知らなくてよい）
* 行き過ぎても戻れるよう二分探索にし、字体と画像が揃うまで測らない

実測（手元・実データ）: **13社＋ほか37社**が載り、下切れ無し。e2e に
「受付なしの社名が0社にならない」を1本追加した。
