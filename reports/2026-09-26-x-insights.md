# 自分の X の投稿を毎日 23 時に AI で分析して Discord へ

## 指示

本人 2026-09-26:

> 一日に１回自身のXの投稿内容を分析したものをDiscordに流せる？インプ数はこれで詳細を見られた数はこうで特にこの投稿が伸びて伸びた理由は～みたいなのがあるといいかも

> OK、じゃあX投稿の分析をするようにして、AIがしっかり見て、内容を分析した要約とかも出してくれると嬉しい。こういうのが伸びる傾向にあるとかもわかるとなおいい。

> 投稿先はここね。（webhook）／２３じ

## PR

https://github.com/shinonomeheta-ai/cardbot/pull/1681 （ブランチ `x-insights`・92cb474e4）

### 中身
- `x_insights.py`
  1. X API（投稿に使っている OAuth 1.0a の鍵・自分のアカウント）で、直近7日の自分の投稿（リポスト・返信を除く）と数字を読む。GET の問い合わせも署名に入れる署名を持つ（`x_post._oauth_header` は POST 用で問い合わせを入れていない）
  2. `x_insights_history.json` に積む（投稿ごとに本文・画像の有無・リンク・ハッシュタグ・数字・日ごとの表示）。前に見た日との表示の差＝「この1日で伸びた数」。90日より古い投稿は落とす
  3. 直近30日の投稿と数字を Claude Sonnet 5 に渡し、JSON で要約・特に伸びた投稿と理由・伸びる傾向・伸びにくい傾向・次に試すことを返させる。数字に無いことを事実として書かない・推測と分かる言い方にする、と指示
  4. Discord へ送る。投稿の URL は `<>` 付きの押せるリンク
- 数字: 表示・リンクのクリック・プロフィールのクリック・エンゲージメント（非公開の数字）、いいね・リポスト・返信・引用・ブックマーク（公開の数字）。「詳細のクリック」は X が返したときだけ出す（v2 の API では返らないことが多い）。非公開の数字を断られたら（契約・権限）公開の数字だけで出し、その旨を文面に書く
- 送り先: 分析専用の webhook。GitHub の secret `X_INSIGHTS_WEBHOOK_URL` に登録済み（値はリポジトリ・報告に書かない）。ほかの通知の webhook には落とさない
- 起動: 23:00 JST に Vercel の定時処理（`web/app/api/watch/route.js`）が `x-insights.yml` を起こす（`crawl.mjs` の `CARDBOT_JOBS`・収集 v2 の朝の回と同じ仕掛け）。GitHub の schedule（23:40 JST）は保険。同じ日の分を送り終えていれば何もしない
- 分析する日: 23時に走るのでその日。20時より前に走ったとき（遅れて日をまたいだ・手動）は前の日
- 費用: X の読み取り（自分の投稿は1件 $0.001）で直近7日×1日1回＝月 $2 程度。AI は1回の見積もりが $0.50 を超えたら呼ばない。実際の費用は履歴の `reports[日付].ai_usd` に残す

### 使えるようになるまで
- マージ後、Vercel の再デプロイで 23:00 の起動が入る。初日は前日の数字が無いので「この1日で伸びた数」は出ず、2日目から出る
- 手で試すとき: Actions の `x-insights` を `dry_run` 付きで実行するとログに文面が出る（Discord へは送らない）
