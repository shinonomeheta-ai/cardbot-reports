## 2. 新しい調査 → **支店の告知は1行も混ざっていません**

### ① 突き合わせは前方一致か完全一致か → **完全一致**

```
roundsOfChain   keys.has(normStore(l.store))     Set の完全一致
chainOfStore    keys.includes(normStore(store))  配列の完全一致
```

`golden-chains.mjs` に `startsWith` も部分一致もありません（コードで確認）。
`normStore` は**空白を落として小文字にするだけ**で、記号も語も落としません。

### ② `ブックオフ川崎モアーズ店` のような支店名は鍵に当たるか → **当たりません**

配布データの店名を全部あたって、「**前方一致だったら当たっていた**」ものを数えました。

```
44件   そのどれも、いまは当たっていない

   TSUTAYA の支店            28件（TSUTAYA大垣店／TSUTAYA Trading Card 北千住 …）
   フルコンプ の支店            8件（フルコンプ 仙台駅前店／八王子本店 …）
   ビックカメラ の支店           4件（ビックカメラ新宿東口店／柏店／AKIBA ×2）
   EDION 系                 4件（トレカキャピタル広島本店／横浜西口本店ほか）
```

**この44件が「完全一致が仕事をしている」証拠**です。ここを前方一致にした瞬間に、
TSUTAYA のカードへ支店の抽選が28件入ります。

### ③ カードに集約されている31行に支店の告知は何行あるか → **0行**

```
カードに集約されている配布行   31
うち支店らしい名前            0
```

31行の店名は、チェーン名（`GEO` `平和堂` `楽天ブックス` `エディオン` `ガンギ` …）、
`〜各店`（`ドラゴンスター各店` `イトーヨーカドー各店`）、
通販（`ポケモンセンターオンライン` `ヤマシロヤ オンラインショップ`
`ドラゴンスター通販` `トレカプラザ55通販店`）だけでした。

### 結論

> **いまの構造で問題ありません。突き合わせを直す実装は不要です。**

### ただし逆向きの取りこぼしが2行あります（判断5 の材料）

44件のうち **`エディオン/トレカキャピタル` の2行は支店ではなくチェーン全体の告知**で、
鍵が `エディオン` なので**カードに入っていません**。原則（チェーン全体はカードに入れる）
からすると、これは入るべき行です。

```
エディオン/トレカキャピタル   30th                       締切 08-30   ← 本部の告知
エディオン/トレカキャピタル   拡張パック「30th CELEBRATION」  締切 08-30   ← 本部の告知
（別に トレカキャピタル広島本店／横浜西口本店 の2行は支店なので、入らなくて正しい）
```

判断5（EDION）で「`エディオン/トレカキャピタル` は実店舗を含むので足さない」と
ご判断いただきましたが、**この2行は支店の告知ではなくチェーン全体の告知**でした。
新しい軸（本部か支店か）だと足す側になります。**触っていません。**判断をお願いします。
