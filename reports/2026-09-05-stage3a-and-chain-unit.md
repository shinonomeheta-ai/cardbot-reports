## 3. B の問いへの答え（実測）

### ③ M1g の52チェーンはどの単位か → **チェーン単位。`store_keys` で店の行を束ねている**

`web/public/data/golden_chains.json` の1件はこの形です。

```json
{ "canonical_name": "イエローサブマリン",
  "store_keys": ["イエローサブマリン", "イエローサブマリン各店"] }
```

**52チェーンのうち17が、複数の店キーを束ねています。**

```
イエローサブマリン   ['イエローサブマリン', 'イエローサブマリン各店']
フルコンプ        ['フルコンプ', 'フルコンプ 通販', 'フルコンプ(一部店舗)', 'フルコンプ各店']
駿河屋          ['駿河屋', '駿河屋 通販', '駿河屋通販']
ヤマシロヤ        ['ヤマシロヤ', 'ヤマシロヤ オンラインショップ', 'ヤマシロヤオンライン', 'ヤマシロヤ通販']
ドラゴンスター      ['ドラゴンスター', 'ドラゴンスター各店', 'ドラゴンスター通販']
イトーヨーカドー     ['イトーヨーカドー', 'イトーヨーカドー各店']
EDION          ['エディオン', 'トレカキャピタル']
BIC CAMERA     ['ビックカメラ', 'ビックカメラ各店']
  …ほか9件
```

**「チェーン全体と『各店』をどう扱うか」の答えは、M1g が既に持っています。**
別の行のままにして、`store_keys` で束ねる、が現行の設計です。

### ① 「チェーン全体」の表現 → **2つある。片方は慣習、片方は仕組み**

```
慣習   台帳の店名の語尾   〜各店 29行 ／ 〜店舗 21行 ／ 〜全店 1行
       公式X表の鍵の語尾  〜各店  4件 ／ 〜店舗  4件 ／ 〜全店 1件
仕組み  golden_chains.json の canonical_name ＋ store_keys[]
```

**語尾はコードのどこにも意味を与えていません。** 「各店」「店舗」を
チェーン全体と読んでいるのは人だけで、機械は `store_keys` しか見ていません。
（案B の `_売り方` も `各店` `店舗` は見ていません。売り方の語だけです）

### ② [P1] との整合 → **軸が違う。束ねてよいのは「表示の枠」、束ねてはいけないのは「権限」**

M1g は**両方の扱いをしています**。

```
分ける   ポケモンセンター(実店舗)  ←→ ポケモンセンターオンライン   別のチェーン
        イトーヨーカドー        ←→ イトーヨーカドーネットスーパー  別のチェーン
束ねる   駿河屋 ＝ ['駿河屋', '駿河屋 通販', '駿河屋通販']       同じチェーン
        フルコンプ ＝ ['フルコンプ', 'フルコンプ 通販', …]        同じチェーン
```

一見矛盾しますが、**M1g は「ネット販売タブに何枠出すか」を決める表**で、
[P1] は「そのURLをその店のものとして配ってよいか」を決める規則です。
軸が違うので両立します。

```
M1g（配信の枠）   駿河屋の通販も「駿河屋」という1枠に出してよい
[P1]（権限）      駿河屋に登録したURLを駿河屋通販へ効かせてはいけない
```

**したがって、こう整理できます。**

> 束ねてよいのは**表示の枠**（M1g の `store_keys`）。
> 束ねてはいけないのは**権限**（公式X表・店サイト表・共有基盤の登録）。
> 台帳の行は分けたまま、束ねるのは M1g の側でだけ行う。

案B で `_売り方` の線を引いたのは、**権限の側の話ではなく探索の対象選び**でしたが、
結果として同じ線を引いています。整合しています。

### この答えから、(c) 3件と 12件はどうなるか

M1g にいるかどうかで、判断材料の有無が分かれます。

| 件 | M1g | 言えること |
| --- | --- | --- |
| `イトーヨーカドー` / `イトーヨーカドー各店` | **同じチェーン**（`イトーヨーカドー`） | 束ねる判断は済んでいる。**台帳の行は分けたままでよい** |
| `フルコンプ` / `フルコンプ各店` | **同じチェーン**（`フルコンプ`） | 同上。ただし公式Xが別々（@fullcomp_jp と @fullcomp_online）で、後者は**オンラインの口** |
| `イエローサブマリン` / `イエローサブマリン各店` | **同じチェーン** | 同上 |
| `トイコンプ` / `トイコンプ各店` | **M1g に無い** | 判断材料が無い。M1g へ登録するかが先 |
| `トレカエース` / `トレカエース各店` | **M1g に無い** | 同上 |
| `カードラボ` / `カードラボ店舗` | **M1g に無い** | 同上 |
| `ゲオ` | **M1g に無い** | 同上 |
| `ポケモンセンター` / `ポケモンセンターオンライン` | **別のチェーン** | 分ける判断は済んでいる。案B の扱いと一致 |
| `ノジマ` / `ノジマオンライン` | `ノジマオンライン` だけ M1g にいる。`ノジマ` は無い | **@enetjp（表示名『ノジマオンライン』）が `ノジマ` に付いているのが誤り**。正しくは `ノジマオンライン` の行へ |
| `駿河屋` / `駿河屋 通販` | **同じチェーン** | 表示は1枠。権限は分けたまま（案B の扱いと一致） |

**M1g にいる分は、追加の判断なしで処理できます。** M1g に無い分（トイコンプ・
トレカエース・カードラボ・ゲオ）は、**M1g へ登録するかどうかが先**で、
それは M1g の設計判断です。
