## 2. なぜ効かないか——KIDS REPUBLIC とは中身が違う

案Bのナビ落としは「**強い手がかり（その回の日付か商品の固有部）が1つも無い**」と
「**ナビらしい**」の**両方**が成り立つときだけ落とす。ナビらしさは
「句点が無い・語が短い・**数字を含む語がほとんど無い**」で見る。

```
KIDS REPUBLIC 556字   キッズリパブリック｜キャンペーン一覧 … MENU トップページ TOP APP …
                      → 数字が1つも無い＝ナビらしい＝落ちる

ホビーサーチ 2000字   【抽選販売】 ザク・マリナー (HGUC) ガンプラ｜ホビーサーチ …
                      【抽選販売】 30MS 遠坂凛 プラモデル｜ホビーサーチ …
                      → (HGUC)・30MS・RGZ-91 と数字入りの語が多い＝ナビらしくない
```

**そして、これは案Bで落とすべきものではないと思う。** これはナビではなく
**別商品（ガンプラ）の本物の抽選告知**である。落とす理由は「ナビだから」ではなく
「**候補の商品（ドラゴンボール `EVOLUTION`）と別の商品のページだから**」で、
判定の軸が違う。

長さで落とす案（2000字ちょうどだから怪しい）は採らない。**実測で `ok` の 2 割は
135〜200字の短い本物の告知**なので、長さは弱さの証拠にならないのと同じ理由で、
長さは怪しさの証拠にもならない。

## 4. 本文の起こし方は壊れていなかった（疑って測った・負の結果）

抜粋の頭に `(function(w,d,s,l,i){w[l]=w[l]||[];w` が入っていたので、
「HTMLコメントの中のスクリプトを落とし損ねている」と疑って測った。**外れた。**

```
いまの _素の文字 に <!-- <script>var a=1;</script> $(function(){…}); --> を通す
  → '本文'（コメントごと落ちる。壊れていない）

保存済み本文 2,366本のうち JS/CSS が残っているのは 51本（2%）
  → **51本すべてが `EF.extraction_residue()` に引っかかる**
  → `build_evidence_cache` は残骸のある本文を「新しい」と認めない配線を持っている
     （`build_evidence_cache.py:747`）ので、**次の巡回で取り直される**
```

08-31〜09-02 に取った古い本文の残りで、放っておけば消える。**直すものは無い。**
