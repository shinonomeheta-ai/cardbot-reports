### 2-1. HMV（文字コード）— これが本命

```
Content-Type: text/html; charset=Shift_JIS
meta charset: Shift_JIS

utf-8  でデコード: UnicodeDecodeError（"replace" で全部化ける）
cp932  でデコード: 「抽選」3件・ラベルが読める
```

取得側は `decode("utf-8", "replace")` が固定です（`linked_page_cache.py:236`・`url_quality.py` の複数箇所・`ec_lottery_watch.一覧を開く`）。Shift_JIS のサイトは:

1. 一覧のラベルが化けて**関心語（「抽選」）で全部落ちる** → 記事リンク 0
2. 仮に記事URLが取れても、**記事本文も化けて `ページは抽選か()` が False** → seen に入らない

HMV は `search`（`site:hmv.co.jp 抽選 カードゲーム`）も持っていて、検索の道では記事が5本取れます（`260714121` = ストームエメラルダの抽選販売受付）。**取れても本文が化けるので、そこで落ちます。**

直すなら、取得のときに `Content-Type` ヘッダーと `<meta charset>` を見てデコードします。判定は1か所（`linked_page_cache` の取得）に寄せられます。**Shift_JIS のサイトが他に何社あるかは未測定**です。

### 2-2. イエローサブマリン・iAEON（一覧に抽選記事が載らない）

- イエローサブマリン: `any=True` なので関心語は不要で記事リンク6本が取れますが、中身は「9/7休業のお知らせ」「営業時間変更」など。**抽選の告知が一覧に載っていません**（告知は公式X）。`search` が未設定なので検索の道もありません。
- iAEON: 記事リンク1本（花火大会・受付終了）。ポケカの `archives/125` は一覧の上位に無く、`search` 未設定。

2026-08-31 の実測（「15社の一覧に抽選記事のリンクが1本も無かった」）と同じ型です。この2社に `search` を足せば検索の道が使えます。

### 2-3. ヤマダ（link パターンが古い）

```
list  https://www.yamada-denki.jp/contact/          200・42KB（読める）
link  yamada-denki\.jp/contact/pmcg[^"]*            → contact ページに pmcg リンクは無い（一致0）
実際の告知  https://www.yamada-denki.jp/information/260223_pokemon-card/   200・21KB
```

`pages`（AIが見つけた学習ページ）には `information/260223_pokemon-card/` が入っているので、そちらは毎回見ています（seen 1）。ただし**その1本だけ**で、新しい回の告知は拾えません。`link` を `information/\d+_pokemon-card` の形にすれば拾えます。
