# 全国店舗タブ: 位置情報のフィルターは「消えていた」のではなく埋まっていた（PR #1503）

日付: 2026-09-09 / セッション: uidesign
前の報告: [2026-09-09-lottery-mobile-mock.md](https://github.com/shinonomeheta-ai/cardbot-reports/blob/main/reports/2026-09-09-lottery-mobile-mock.md)

## 受けた指示（本人・チャット）

> もともとあった商品ページは各支店情報を表示　店舗ページは大手チェーンにあった店舗
> フォロー中も店舗のフォロー中を表示　条件達成済みも同じ。
> 全国店舗は前あった通り位置情報を使ったフィルターが出るように

## 最初に測った（言い当てにいかなかった）

「フィルターが出ない」と聞いて、まず**出ていないのか、出ているが見えないのか**を
分けた。390px の実ビューポートで `?tab=lottery` の要素の位置をそのまま測ると、

```
axisTabs: ["商品","店舗","フォロー中","条件達成済み"]   ← 4つとも居る
regionask: あり                                        ← 位置情報の促しも居る
filter:    「絞り込み（すべて）70件を表示」              ← 絞り込みも居る
```

**全部あった。** 出ていないのではなく、**画面のずっと下にあった**。

## 本当の原因

抽選の入口を1つにまとめたとき、`GoldenChainCards`（大手チェーンの札）の呼び出しが
**両方のタブを通る**ようになっていた。全国店舗の先頭に55枚・**3,459px**（約4画面ぶん）が
挟まり、この画面のものが全部その下へ押し出されていた。

| | 直す前 | 直したあと |
|---|---|---|
| 大手チェーンの札 | 464px（3,459px ぶん） | 出さない |
| 店舗ごとの応募条件 | 3,935px | 464px |
| **地域（位置情報）の絞り込み** | **4,039px** | **568px** |
| 絞り込み（70件を表示） | 4,124px | 652px |
| 支店のカード | 4,176px | 704px |
| その他の店の抽選 | 8,462px | 4,990px |
| ページ全体の高さ | 12,503px | 8,747px |

指示の他の3つ（商品＝各支店情報／店舗／フォロー中／条件達成済み）は**もともと
そのまま動いていた**。同じ理由で下に埋まっていただけなので、この1か所で戻る。

## 直したこと

`goldenOnly` のときだけ大手チェーンの札を出す。JSX の1か所（page.js）だけ。
大手チェーンタブは変わらない。
