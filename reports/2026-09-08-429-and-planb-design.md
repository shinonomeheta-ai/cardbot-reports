## 2. 案B の設計

metrics の分解（時点 2026-09-08 12:21 JST・母数 active で AI へ送れない 410回・
定義 `candidate_ai_cache.unsendable_reason`）を受け取った。

```
案Bが直す相手  excerpt_missing        245回 15社   本文はあるが抜粋が作れない
案Bでは直らない 抜粋の行が無い          97回
               not_official           35回
               本文が1本も無い          21回
               stale                    8回
               event_store_mismatch     4回
別集合         関門は通るが AI が       285回 174社  抜粋の中央値 168字
               insufficient_evidence               （KIDS REPUBLIC 型）
射程合計                               530回
```

### 仕組みの特定（実測）

KIDS REPUBLIC が **556字のナビ文言で `excerpt_status: ok`** になる仕組みを突き止めた。

`candidate_evidence_excerpt` の点数は `1 + len(当たった)` で、`MIN_HITS = 2`。
つまり**手がかりが1語当たれば通る**。手がかり（`手がかり()`）には
`game` と `event_type` が入っている。

```
店='キッズリパブリック（アプリ）'  product=''  game='遊戯王'  event_type='抽選'
語たち=['遊戯王', '抽選', '4/3', '4月3日', ...]
抜粋= キッズリパブリック｜キャンペーン一覧・抽選情報【イオン公式】 …（556字・全部ナビ）
```

ページ題名の**「抽選情報」が `event_type` の「抽選」に当たる**。点は `1+1=2` で
`MIN_HITS` を満たし、ナビだけの抜粋が `ok` になる。

### 【重要】素直な直しは 21% を落とす

「日付か商品固有語が周辺に無ければ採らない」をそのまま入れると**採れなくなる回が
多すぎる**。母数は `excerpt_status == ok` の 2,147回（`rounds_of` 2,877 のうち）。

```
日付か商品固有語が当たっている（強い）   1,690
ゲーム名・種別だけで通っている（弱い）     457   ← ここが全部落ちる
手がかりが1つも当たらない                    0
```

**457回（21%）** が落ちる。しかも中身を見ると、KIDS REPUBLIC のようなナビだけの
長文ではなく、**短い本物の告知**が混ざっている。

```
crnd_prov_9c8f27ca47f2  TSUTAYA辰巳台店        当たり=['抽選']            抜粋135字
crnd_6d032d2ba605       ビックカメラ AKIBA      当たり=['抽選']            抜粋170字
crnd_prov_eb1b5ca74424  ブックオフ4号せんげん台店  当たり=['ポケモンカード','抽選'] 抜粋167字
```

`product` が空の回が多い（store-name-a も「昇格で落ちた8件は全部 台帳の商品名が
空」と報告している）ので、「商品固有語」を必須にすると**台帳の欠けがそのまま
抜粋の欠けになる**。

### 設計（この形で作る）

**「弱い手がかりだけ」を落とすのではなく、「節に割ってから、その節の中で見る」。**
案Bの原文（長いページを節に割ってから店名を探す）に忠実にする。

1. **節に割る** — 本文を見出し・空行・区切りで節へ分ける
2. **節ごとに店名を探す** — 当たった節だけを候補にする（いまは本文全体で位置を測る）
3. **節の中の手がかりで点を付ける** — 節の外の語は数えない
4. **ナビだけの節を落とす基準は「弱い手がかりしか無く、かつ節がナビらしい」**
   ——ナビらしさは、リンク文言の連なり（短い語の羅列・区切り記号が多い）で見る。
   **長さだけでも弱さだけでも落とさない**（上の457回を守るため）

短い本物の告知は「節がナビらしくない」ので残る。KIDS REPUBLIC は節がナビそのもの
なので落ちる。

### 受入基準（store-name-a の提案を採る）

- ナビだけの節を採らない **かつ** KIDS REPUBLIC の11回が
  `insufficient_evidence` から動くこと（前者だけだと「何も採らない」でも通る）
- **`excerpt_status == ok` の回が 2,147 から大きく減らないこと**（私が足す条件。
  減りが 457 に近ければ設計が間違っている）

### 縛り（指示どおり維持）

**抜粋を作るところまでで止める。** 商品名など台帳へ書く口は足さない
（`candidate_event_id` が動くため）。

### metrics へ1つ頼みたいこと

`excerpt_missing 245回15社` の **`round_id` の一覧**をもらえると、直したあとに
「245 のうち何回が ok になったか」を同じ集合で測れる。出せると言ってくれているので
依頼する。
