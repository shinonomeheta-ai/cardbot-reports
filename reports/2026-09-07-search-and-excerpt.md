## 1. 検索の道（PR #1440）

### 4つの検索を1社ずつ測った

`site:<host> 抽選 カードゲーム` で、4つの検索エンジンそれぞれの戻りと、記事URLが何本入っているかを数えました。

| 社 | Yahoo | DDG | DDG lite | Brave |
| --- | --- | --- | --- | --- |
| イオン九州 | 398KB・記事 **0本** | 14KB・結果なし | 14KB・結果なし | 204KB・記事 **4本** |
| HMV | 399KB・記事 **5本** | 14KB・結果なし | 14KB・結果なし | 429 |
| イエローサブマリン | 392KB・記事 0本 | 34KB・0本 | 21KB・0本 | 429 |

Yahoo は動いています。ただし**社によっては結果に記事が出ません**。イオン九州は Brave なら 4本取れます。

### 原因

```python
def search_any(query, timeout=20):
    try:
        return yahoo_search(query, timeout=timeout)   # ← HTTP が通れば即 return
    except 検索できない:
        pass
    for 名, fn in (("DDG", ddg_search), …):
        …
        if _結果がある(html):
            return html
```

`_結果がある()` の判定は **DDG・Brave にしか使われていません**。Yahoo は HTTP が通れば中身を見ずに採用され、そこで打ち切られます。「返ってきた」と「欲しいものが入っている」を分けていませんでした。

### 直し方

`search_any(query, timeout, 十分か=None)` を足しました。

- `十分か(html)` を渡すと、**呼ぶ側が「入っているか」を決められる**。足りなければ次の検索へ進み、**取れたものを足して**返す
- 渡さなければ**今までどおり**（既存の公式X探索は1文字も変わらない）
- どれも足りなければ**取れた分を返す**（「検索できない」と混ぜない）

`ec_lottery_watch.検索で一覧(host, query, pat)` が記事URLの形を渡します。

### 効き目（実測）

```
iAEON              0件 → 4件   archives/125（30th CELEBRATION 抽選販売のお知らせ）を含む
HMV                5件 → 5件   Yahoo で足りるので追加の検索を叩かない（正しい挙動）
イエローサブマリン   0件 → 0件   Brave が 429 で試せず。サイトに抽選記事が無い可能性もある
```

**無駄に叩きません。** 足りていれば次へ進まないことを試験で固定しました。

### ご指示への回答

- 描画（`url_quality` の描画の道）で読めるか → **不要**。Yahoo は静的HTMLで結果を返しています。
- Yahoo 以外を使う手があるか → **既にあります**（DDG・DDG lite・Brave）。使われていなかっただけです。Bing は今回追加していません。
- いつから返っていないか → **返っています**（私の読み違い）。

## 2. 抜粋が作れるか（本人指示 4）

### HMV は通ります
文字コードの修正（#1437）で、**読める → 抽選ページと判定される → 抜粋が作れる**まで通りました。本人のご指摘の「正式店名を名乗らないページで195回落ちた」型にも当たっていません（本文に `HMV&BOOKS online` が入っています）。

### ヤマダは通りません
HTTP 200・21KB で取れますが、**本文テキストは 74字**（タイトルのみ）です。中身が画像なので、テキストに応募期間も商品名も入っていません。これは 2026-09-03 の調査（「本文は画像。テキストから応募方式を確定できない」）と一致します。

つまりヤマダは:

```
サイトは読める（site_blocked は付けない・#1432 のとおり）
記事URLは拾える（#1438 で link パターンを直した）
本文が画像なので抜粋が作れない  ← ここで止まる
```

画像の道（2026-09-05 に入った V5 の画像レーン）に載せられるかは、別に見る必要があります。今回は測っていません。
