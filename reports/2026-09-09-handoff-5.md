## 2. B — 締切の近い順に聞く（費用ゼロ・次にやること）

**いまの並びは `input_fingerprint` 順で、締切順ではない**（memory
`ai-queue-order` にも記録がある）。

```
送れる回 1,334件 ／ 1日20件 ／ 全部聞くのに67日
抽選の締切は数日〜2週間先
→ **順番が回る前にほぼ全部が締切切れになる**
```

**同じ20件でも、締切の近い回を先に聞けば画面に出る率が上がる。費用は1円も増えない。**

実測（★8社の例）:

```
YAMADA   crnd_0fb616ff105f  送る並びの 53番目   → 約3日後
セブンネット crnd_cb80d02bfe85  送る並びの736番目   → 約37日後（締切に間に合わない）
```

**直す場所**: `candidate_ai_sonnet_direct.select_targets()` / `check_candidates_ai.対象()`
の並び。**`limit` で切る前に締切順に並べ替える**。

**注意**: 並べ替えは「どれを聞くか」を変えるので、**費用は変わらないが結果は変わる**。
`input_fingerprint` 順にしていた理由が他にあるかもしれないので、
**コードのコメントと git 履歴を先に読むこと**。
