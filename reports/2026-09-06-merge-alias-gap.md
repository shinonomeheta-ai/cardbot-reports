## 4. 根っこ — ロスターの別名 132本のうち 23本が、構造的に一度も当たりません

`store_identity()` は2段で寄せます。

```
① canonical_store()      store_aliases.json
② lottery_stores.json の keys   ← ここが効いていない
```

②の突き合わせは `alias in ns` ですが、**両側の作り方が違います**。

```
_store_aliases()    キー = 空白落とし ＋ 小文字        （小書きカナはそのまま）
_norm_store_text()  ns  = 空白落とし ＋ 小文字 ＋ **小書きカナを大書きへ畳む**
```

キー側に小書きカナ（ァィゥェォッャュョ）が1文字でもあると、`ns` 側では大書きに
なっているので**絶対に当たりません**。

```
'エディオン'  in  'エデイオン/トレカキヤピタル'   → False（ィ と イ）
```

**132本中23本**が該当します。`エディオン` `ビックカメラ` `ブックオフ` `楽天ブックス`
`ホビーステーション` `キッズリパブリック` `セブンネット` `キディランド` `ジョーシン`
`ファミマ` `トレカキャピタル` …。**大手ほど当たっていません。**

これは §11-1-1 と同じ形（規則は1つでも、材料＝正規化が2つある）の4例目です。

**同じ店になってしまう組が1つあります。**

```
'トレカキヤピタル'  ← エディオン/トレカキャピタル（本部の告知）
                    トレカキャピタル広島本店（支店）

```

**本部の告知と支店の告知が同じ店になります。** §3-1-1-c（主体が本部か支店かで
区別する）に正面から反するので、**この案は単独では採れません**。
`キデイランド二子玉川店 → kiddyland` も同じ形です。

原因は②が**部分一致**だからです（`alias in ns`）。①は完全一致なので安全ですが、
②は支店名の中にチェーン名が入っているだけで当たります。

## 6. 選択肢（実装していません）

### 案1: `store_aliases.json` の `エディオン` に2つの綴りを足す（最小）

```
"エディオン": [… , "エディオン/トレカキャピタル", "エディオン・トレカキャピタル"]
```

いま鳴っている2行が直ります。**副作用は `lot_key` が動くこと**——配る側
（`build_lotteries_nyuka`）が `canonical_store` で店名そのものを書き換えるためです。

```
エディオン/トレカキャピタル|pokemon|2026-08-30|30th          → エディオン|…
エディオン/トレカキャピタル|pokemon|2026-08-30|30thcelebration → エディオン|…
```

**この2行は締切が 2026-08-30 で既に過ぎている**ので、利用者の応募済み・既読への
実害は小さいと見ています。`トレカキャピタル` は既に同じ別名表に入っているので、
このチェーンでは確立した形でもあります。

### 案2: りらいも同じ形で足す（再発を止める）

```
"カードゲームショップ りらい（福島）": ["りらい(福島)"]
```

こちらは**締切 2026-09-15 で受付中**なので、`lot_key` が動くと
**いま応募済みを付けている人の印が外れます**。案1より慎重に決めてください。

### 案3: ②のキーも `_norm_store_text` で畳む（根っこ）

23本が生き返りますが、§5 のとおり**本部と支店が同じ店になる組**が出ます。
**単独では採れません。**

### 案4: 案3 ＋ ②の部分一致をやめる（設計の変更）

②を完全一致にすると支店の巻き込みは消えますが、いま②が正しく畳んでいる分
（`TierOne 渋谷店` と `TierOne 浜松店` を同じ店と読むなど）も止まります。
**別の区切りで、合流の設計として決めるべき**だと思います。

## 7. #1333（`extra_store_keys`）との関わり

案1 を採ると、配布データの店名が `エディオン` へ書き換わります。すると
**#1333 で M1g に足した `エディオン/トレカキャピタル` は、配布データには
出てこない名前になります**（候補台帳には残るので鍵自体は残ります）。

```
案1 を採る    配る名前は「エディオン」に寄る   → M1g の鍵は エディオン だけで足りる
案1 を採らない 配る名前は2つのまま           → M1g の鍵は #1333 のまま要る
```

**どちらの名前で配るかを先に決める必要があります。** 両方は成り立ちません。
