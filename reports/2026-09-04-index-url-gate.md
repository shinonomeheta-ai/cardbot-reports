### 実装したもの

`publish-report.sh` に関門を1つ足した。コミット `58bafb9`。

置いた場所は「索引にその報告の行があるか」の検査の直後、追記検査より前。

検査の内容:

- 索引の本表（6列）の行だけを見る。`awk` の `FS="|"` で分けて **フィールド数が8の行**が本表。
  「列の意味」の表（2列）や README の例（3列）は対象外になる
- 4列目（報告ファイル）を取り出し、前後の空白を落とす
- 見出し行（`報告ファイル`）と区切り行（`---`）は飛ばす
- `本文なし（チャットのみ）` は**例外として通す**
- それ以外は `[表示名](絶対URL)` の形で、URL が
  `https://github.com/shinonomeheta-ai/cardbot-reports/blob/main/reports/` で
  **始まり、かつ前置きより長い**（＝ファイル名が付いている）ことを求める
- 満たさない行があれば **push を止め、行番号つきで該当行をそのまま表示する**

**検査は索引の全行を見る。** その報告の行だけを見ると、別セッションが足した崩れた行を
拾えない。実際にすり抜けた1行も別セッションのものだった。全行を見るので、誰かが崩した
まま放置されていても、次に誰かが報告を出したところで止まって直される。

止まったときの表示:

```
reports/INDEX.md の「報告ファイル」列が絶対URLでない行がある（決まり5）:
  12行目: | 2026-09-04 | 捕捉率の全数測定 | … | [2026-09-04-x-intake-capture-rate.md](2026-09-04-x-intake-capture-rate.md) | 判断待ち | 確認中 |
  前置きは https://github.com/shinonomeheta-ai/cardbot-reports/blob/main/reports/ で固定する。
  本文がまだ無い報告だけ「本文なし（チャットのみ）」を書ける。
```

`reports/README.md` の決まり5にも「この決まりは `publish-report.sh` が機械で見張る」を
書き足した（決まり6・7と同じ形にそろえた）。

### 試験

使い捨ての git 置き場（bare を origin にした clone）を作り、8通りで確かめた。
`REPORTS_REPO` で置き場を差し替えられるので、本物の置き場には触れていない。

| 試験 | 期待 | 実際 |
| --- | --- | --- |
| 全部絶対URL | 通る | 通る |
| 相対パス `[名](名.md)` | 止まる | 止まる |
| `./` 付き相対パス | 止まる | 止まる |
| raw URL（`raw.githubusercontent.com/...`。別形式） | 止まる | 止まる |
| リンクですらない（ファイル名の素書き） | 止まる | 止まる |
| **別セッションの行だけ**が相対パス | 止まる | 止まる |
| `本文なし（チャットのみ）`（例外） | 通る | 通る |
| 絶対URL＋`#見出し` | 通る | 通る |

8件すべて期待どおり。

「通る」が**関門より手前で落ちて通ったように見えているだけ**ではないことも別に確かめた。
良い索引で最後まで走らせると raw URL を返して `rc=0` で終わり、origin に
`report: 2026-09-04-t.md` のコミットが入る。関門は確かに素通りしている。
（最初に書いた試験は置き場に upstream を張っていなかったため `git pull` の段で
全件が落ち、**全部「通る」に見えていた**。「止まる方が1件も無い」という結果の形が
おかしいことに気づいて harness の側を直した。）

現在の本物の索引に対して検査を掛けると、**検出0件**。
