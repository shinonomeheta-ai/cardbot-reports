## 1. 【設計の訂正】案B の相手は「長いページ」ではなかった

昨日の設計で「長いページを節に割る」と書いたが、**245回の材料を実際に測ると
そうではなかった**。

```
245回の材料 323本
  中央値の長さ  195字     ← 長いページではない
  媒体          Xの投稿が大半
  長い材料(3,000字以上)を持つ回  78 / 245
```

**anchor（店名）の位置を測ったのが決め手だった。**

```
短い材料 70本のうち
  anchor の位置（本文に占める割合）  78%（中央値）
  本文の半分未満しか渡せていない     57 / 70
  切った中の手がかりが 0            66 / 70
  本文全体では手がかりがある        65 / 70
```

つまり **店名は告知の末尾（ハッシュタグ・署名）にあり、切り出しは店名から
後ろだけを取るので、告知の本体を丸ごと捨てていた**。

実データ（194字の投稿・カードボックス岡山駅前店）:

```
【抽選】ポケモンカード ・拡張パック30thCELEBRATION ・デッキセット
配布期間:9/5~ 9/11  当選発表:9/15  引換期間:9/16~ 9/23
…
#カードボックス岡山駅前店          ← anchor は 158字目
```

渡していたのは **158〜194 の 36字**。日付も商品名も落ちていた。

**設計の名前（節に割ってから店名を探す）は正しく、私の見立てが違っていた。**
「節」は長いページの見出し区切りではなく、**1件の告知そのもの**が主だった。

## 2. どう直したか（PR #1468）

**(1) anchor を含む節をそのまま抜粋にする**

節は、Xの投稿なら投稿ぜんぶ（版4の「1つの投稿は1つの文脈」）、Webなら
見出しらしい行で割ったもの。HTML→text は見た目の1行ごとに空行を挟むので、
**Webでは空行で割らない**。

**前の店の記載は跨がない。** 節の頭まで戻れるのは、あいだに他店の名前が
1つも無いときだけ。あれば従来どおり anchor から始める。

> [P0] 2026-08-22 の性質を壊しかけた。最初の実装は「前の店の名前の直後」
> から始めており、**その店の本文が抜粋の頭に付いた**。`test_candidate_ai_runner`
> の境界の守り 8件が落ちて分かった。**守りが仕事をした。**
> 直したあとは `支店の境界`・`他店の境界` を1件も書き換えていない。

**(2) ナビだけの節は採らない**

落とすのは「弱い手がかりしか無い」と「ナビらしい」の**両方**が成り立つときだけ。
弱いだけで落とすと `ok` の2割（457回）を失う——これは昨日の実測どおり。

ナビらしさは**語で数える**。キッズリパブリックの556字のナビは**改行が1つも
無く**、行では測れなかった。見るのは3つだけ（句点が無い／語のほとんどが短い／
**数字を含む語がほとんど無い**）。告知には日付・価格・本数が必ず入る。

判定は `強い手がかり()` の**1か所**（§11-1）。`_応募回固定の抜粋` も同じ語彙を
使うようにした。

### キッズリパブリックは「一部」——正直に書く

23回のうち **7回が `ok` から外れ、16回は `ok` のまま**。

16回が残るのは設計どおり。節の頭まで戻ったことで抜粋の頭が

```
前: キッズリパブリック｜キャンペーン一覧・抽選情報【イオン公式】 イオンの…
後: ポケモンカードゲーム 応募手続き【MEGA 拡張パック ニンジャスピナー】｜…
```

に変わり、**商品の固有名が当たる＝強い手がかりがある**ので落とさない。
中身としては「どの商品のページか」がAIへ伝わるようになった改善だが、
**日付は依然としてページに無い**ので、AIが `insufficient_evidence` を
返すかどうかは次の巡回を見ないと分からない。

store-name-a が挙げた「11回」の `round_id` を持っていないので、
**その11回が動いたとは言えない**。動いたと言えるのは7回。
