## 3. 本番デプロイが約12時間止まっていた（#1621）

`web/vercel.json` の `ignoreCommand` は **256 字まで**。#1619（`a71f11454`）で
見る対象に `shadow_candidate_evidence_cache.json` を足した回に **219 → 258 字**に
なり、設定の検証で弾かれて**ビルドにも入らずに失敗**していた。

    最後に通った main   ac22b7549  2026-09-17 17:21Z
    最初に落ちた main   a71f11454  2026-09-17 17:28Z
    以降               巡回の push も含めて main は全件 failure

手元の `next build` も `publish.mjs --force` も通るため、手元では気づけない。
ブランチのプレビューは #1619 より前から分かれていたので通っていた。

直し: 一覧を `web/scripts/vercel-ignore.mjs` へ出し、`ignoreCommand` は
`node scripts/vercel-ignore.mjs`（30字）。判定は同じ（差が無ければ建て直さない・
差ありと git の失敗は建て直す）。**256字以内であることを試験で縛った。**

確認: #1621 のプレビュー success（最新 main 込み）→ マージ後の本番 success →
本番の画面で新しい鍵の色（`--key-neutral`）が出ていることを確認。
