# 3. 回答

## a. `092dd440` は **PR の枝**。main には入っていません

```
git merge-base --is-ancestor 092dd440 origin/main  → **入っていない**
git branch -r --contains 092dd440  → origin/feat/estarbox-promoters だけ
```

**ci が今夜 main を取り込み直しても基準はずれません。** 私が今日 main へ入れたのは
#1401 / #1411 / #1412 / #1414 / #1422 / #1424 / #1430 の7本で、**いま open の枝は

## b. 「V5 の対象 +22」は何を数えたか（1行）

**web だけの回のうち「抜粋は作れているが公式由来でない」ものを、根拠のホストで
分類して e-starbox に当たった回数**——`excerpt_origin` を見ずにホストで代用した数です。

同じ数え方をした「② 70」「③ 354」も同じ理由で外れました。**ホストで主体を
決めようとしたのが誤り**で、正しくは `excerpt_status` / `excerpt_origin` を見ます。
**倍率のずれではなく、見る欄の取り違えです。**

## c. 「本部/通販」と「M1g 54社」は **別の括り**

```
本部/通販   私が店名の字面で分けたもの（「〜店」で終わらない）
M1g 54社    golden_chains.json に載っているチェーン
```

**ブックセンター江戸屋は「本部/通販」だが M1g ではありません**
（`golden_chain_index.チェーン('ブックセンター江戸屋')` は空）。M1g は「大手指定」
の表で、字面で自動的に入るものではありません。**私が2つを並べて書いたのは
紛らわしく、誤りでした。**
