# 2. 本当の詰まりは「公式ページの本文が取れていない」

「web だけ・抜粋あり・公式由来でない」116回を、公式根拠の有無で割りました。

```
公式根拠が1本も無い              76   まとめ／共有基盤／未登録 → ③の道か、送らないのが正しい
公式根拠はある                   40
   うち **本文が取れていない**      23   ← **V4（応募ページの本文取得）が届いていない**
   うち 本文はある（抜粋が古い）      17   ← ⑤ と同じ
```

**②の正体は V4 の取りこぼし23件と、抜粋の古さ17件でした。** どちらも登録では
直りません。

# 3. 順番の提案を変えさせてください

いただいた順番は **② → ③ → ⑤ → ①** でしたが、②が消えたので:

```
第1段  **⑤ 抜粋が古い**（321回）      ← ②の17件もここで一緒に直る。費用0
第2段  **① 抜粋が作れない**（292回）   ← ②の残りとは別。費用0
第3段  ③ 共有基盤の主催者登録（S6）     e-starbox 22＋LivePocket 19。費用0
第4段  ②' V4 が届いていない23件         なぜ本文が取れないかを測る
```

**③だけは指示どおり登録で効きます**（`store_platforms.json` の主催者登録・
#1403 と同じ形）。②は登録の一覧から外してください。

> **登録を「足すだけ」と思わないこと。** `store_sites.json` は1名義1URLなので、
> 足すと**別の名義から取り上げます**。今日ジョーシンで実際に起きました。
> 測ってから足す、が正しい順番でした。
