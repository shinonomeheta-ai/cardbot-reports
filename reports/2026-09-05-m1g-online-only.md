## 3-2. 実店舗の鍵（10本）を外した影響

```
いまカードに集約される配布行        31
外したあとカードに集約される配布行    26
カードから行リストへ移る配布行        5
外す鍵と残す鍵が画面で同じになる組    0   ← 二重に出ない
```

**「受付中」が変わるのは1チェーンだけ**です。

```
ドラゴンスター   受付中 3件 → 0件   （実店舗の鍵 ドラゴンスター各店）
```

行リストへ移る5回:

```
ドラゴンスター各店   30th CELEBRATION 系 3件        締切 09-06  web/店頭
ドラゴンスター各店   ストームエメラルダ              締切 08-30  web/店頭
イトーヨーカドー各店  30th CELEBRATION BOX 系        締切 08-31  店頭/店頭
```

**重複しません。** 画面の振り分け（`splitByGolden`）は「鍵に当たればカード、
当たらなければ行リスト」の二択なので、鍵を外した回は**必ず**行リストへ出ます
（コードで確認）。

**鍵が0本になるチェーンが1件**あります。

```
竜のしっぽ   鍵は `竜のしっぽ各店` だけ → 外すと0本 → 「現在受付中の抽選はありません」
```

（ドン・キホーテ・プレイズは元から0本です）

## 3-3. 判断8 の3組（別主体に戻す）

### 測った3点

**① 配布データの店名が割れるか → いまは割れません**

```
ヤマシロヤ オンラインショップ   配布1   ← 既にこの名前で配られている
ヤマシロヤ／ヤマシロヤオンライン／ヤマシロヤ通販   配布0
トレカプラザ55通販店          配布1   ← 同上
トレカプラザ55／トレカプラザ55通販              配布0
DMM通販／DMM                                配布0
```

**② 公式X判定が変わる行 → 0件。** `official_handle()` は `canonical_store` を
通らないので、別名を外しても引き先は動きません。

**③ lot_key が動くか → いまある配布行は動きません。**
`lot_key` は行の生の店名から作りますが、その店名は既に通販側の名前です。

### ただし、外し方に注意が要ります（2点）

**(1) 別名を丸ごと外すと、オンラインの側が3つに割れます。**

```
ヤマシロヤ オンラインショップ ← ヤマシロヤ / ヤマシロヤオンライン / ヤマシロヤ通販
```

外すべきなのは **`ヤマシロヤ`（実店舗のチェーン名）だけ**で、
`ヤマシロヤオンライン` `ヤマシロヤ通販` は同じオンラインの口の書き分けです。
ここまで外すと、オンラインの回が3つの店名に割れて配られます。

同じ理由で、外すのは次の3本だけにするのが正しいと考えます。

```
ヤマシロヤ オンラインショップ ← **ヤマシロヤ**
トレカプラザ55通販店       ← **トレカプラザ55**
DMM通販                 ← **DMM**
```

**(2) `トレカプラザ55通販店` が store_keys から落ちます。**

この鍵は別名経由でしか拾えていません（`通販店` は `SUFFIXES` に無い）。
別名を外すと**チェーンのオンラインの鍵が消えます**。`SUFFIXES` に `通販店` を
足せば拾えます（`通販` と同じ意味の語なので、規則としても素直です）。

**候補台帳の側では、まだ実店舗の名前が入っています**（`ヤマシロヤ` 2件・
`トレカプラザ55` 1件）。別名を外すと、この3件は今後**実店舗の名前のまま配られ**、
カード（オンラインだけ）ではなく行リストへ出ます。原則どおりの動きです。

## 4. 実装の前に決めていただきたいこと

### 判断A: 43本の「チェーン名そのもの」の鍵をどうするか

原則の読み方が2通りあり、**結果が大きく変わります**。

* **読み方1（鍵の面で決める）**: 「オンライン」と書いてある鍵だけを残す。
  チェーン名そのものの43本も外す。
  → **カードに回が出るチェーンは 12 → 3〜4 に減ります**（楽天ブックス・
  ポケモンセンターオンライン・トレカプラザ55通販店 など）。GEO・平和堂・EDION・
  GANGI・フルコンプ・ポケモンカードストアはカードに回が出なくなります。
* **読み方2（実店舗と書いてある鍵だけ外す）**: 各店・店舗の10本だけ外し、
  チェーン名そのものは残す。**推奨**
  → 変わるのはドラゴンスター1チェーン（3件→0）。**ご指示の「支店の抽選が始まった
  ときにカードが受付中になる」という症状は、これで消えます**（実測でも、実店舗の
  鍵が連れてきていた回は各店の5件だけでした）。

読み方2 を推す理由は、材料がある7本が**全部 Web/アプリ応募のチェーン全体の回**
だからです。`楽天ブックス`（配送6件）や `GANGI`（配送2件）まで外すと、
**本当にオンラインの回がカードから消えます**。

### 判断B: 受け取りが店頭のみのチェーン34件をどうするか

「オンラインの店だけ」を**チェーンの単位**で読むと、こうなります。

```
受け取りが店頭のみ   34チェーン（GEO・平和堂・C-labo・お宝創庫・BIC CAMERA …）
配送を含む          17チェーン
受け取りが空         1チェーン（GANGI ※ #1325 で配送に）
```

ただし 2026-09-03 に「**全チェーンを出す。受け取り方法では絞らない**」と決めて
いただいており（`golden-chains.mjs` の冒頭に明記）、そこと正面から食い違います。
**今回のご指示は「抽選（回）」の話と読みました**ので、チェーンの出し分けは
変えていません。ここも違うようでしたらお知らせください。

### 判断C: 竜のしっぽ（鍵が0本になる）

`竜のしっぽ各店` を外すと鍵が0本になり、カードは常に「現在受付中の抽選はありません」
になります。公式X `@shippo_online`・通販サイトがあるので、**オンラインの鍵が
まだ見つかっていないだけ**の可能性が高いです。

* 選択肢1: そのまま0本にする（原則どおり・実態を正しく映す）。**推奨**
* 選択肢2: 外さない（`各店` のまま残す）
* 選択肢3: オンラインの鍵を探してから外す
