## 3. Googleフォームと customform は「描画」の問題

```
docs.google.com  200 / 91,803B / 読める字 255〜1,463
customform.jp    200 / 11,929B / 読める字 49
```

手元・runner・Vercel の**3か所とも同じ**です。塞がれていません。
**中身がJavaScriptで描かれている**ので、生のHTMLに人が読む字がほとんど無いだけです。

**経路を替えても直りません。** 直すなら描画（headless Chrome）が要ります。

ただし**題名だけは生のHTMLに入っています**。

```
「ＴＣＧショップ１９３ 「CEREBRATION」抽選販売応募フォーム」
「【黄鶏屋】ポケモンカードゲーム MEGA 拡張パック 「 30th CELEBRATION 」抽選販売」
「ポケカ『30th CELEBRATION』『Pデッキセット エーフィ・ブラッキー』抽選応募フォーム」
```

商品名は題名から取れます。**締切は取れません**（フォームの本文の中）。

### 私の目印の誤検知（訂正）

Googleフォーム2件に「検査」の印が付きましたが、**誤検知です**。私が目印に
`お使いのブラウザ` を入れていたため、「お使いのブラウザで JavaScript が…」という
案内文に当たっていました。**検査ページではありません。**

## 6. 未確認・限界
