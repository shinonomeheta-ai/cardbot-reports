# 3. S6 を実装しました → PR #1377

## 実測

```
--discover   手元のURLから主催者 14件・販売元を取得
--register   **登録は1件**（KIDDY LAND）
--measure    promoters 1 ／ events 24 ／ read 24 ／ **no_end 0**
```

24件すべてから 会場・商品・エントリー期間が読めました。**素の GET だけ**で、
ブラウザも AI も使いません（**課金0**）。

## 案Aの形（登録の裏取り）

```
KIDDY LAND  https://livepocket.jp/p/hpmzs   販売元 株式会社キデイランド
   店マスタ側の法人名   M1g の legal_name = 株式会社キデイランド
   その裏取り          公式サイトの会社案内 kiddyland.co.jp/company/data/ が
                     「社名 株式会社キデイランド」と名乗っている（実測）
```

**自己申告どうしを突き合わせない**ようにしました。`legal_name` を書くときは
公式サイトの裏取り（`legal_name_evidence`）を必ず添える決まりで、
**空なら試験が落ちます**。

## 登録しなかったもの（14件中13件）

```
株式会社GIRAFULL      販売元は読めたが、公式サイト girafull.co.jp が**保守中**で
                    会社案内が読めない → legal_name を書けない
株式会社インスパイア      フルコンプ。legal_name を裏取りつきで足せば登録できる
株式会社晴れる屋        晴れる屋2。同上
イエローサブマリン ほか    販売元が店名そのもの（法人名ではない）
TSUTAYA各店         主催者が支店ごと。チェーンの主催者ページではない
```

**足せば増える形**になっています。裏取りは1社ずつなので、必要な順にやります。

## 締切の落とし穴（試験に固定しました）

主催者ページの一覧に出る日付は**引換期間**で、応募の締切ではありません。

```
原宿店   一覧の日付 9/16〜9/20（引換）／ 実際の締切 9/8（抽選エントリー期間）
```

**一覧の日付を使うと8日ずれます。** イベントページの「抽選エントリー期間」を読みます。
