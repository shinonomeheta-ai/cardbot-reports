# 1. PR #1412 — 寄せる単位を告知の主体にした

## ①②④ 別名表

```
エディオン         ["EDION"]                     ← 表記ゆれだけ
トレカキャピタル     連結名3綴りをこちらへ            ← 新しい canonical
トレカキャピタル広島本店  2綴りを統合
GEO ← ゲオ        **外した**
```

**広島本店は配布1＋候補34が2つの綴りに分かれ、どちらにも公式Xが無い状態**でした。
1つにまとめて `treca_capital` を当てたので、34件が公式根拠を得られます。

`GEO ⇔ ゲオ` も同一法人（株式会社ゲオストア）ですが、**店舗と通販で別の口**で、
通販側が「ゲオ店舗に関するお問合せは承ることができません」と明記しています。
**「ゲオ」の綴りは実データに0件**なので、今日の配布は変わりません。

## ③ 公式Xの誤登録

```
トレカキャピタル → trecapi_akiba   ← 誤り（**AKIBA 支店だけ**の口）
                → treca_capital   ← ブランド全体の口
```

広島本店の開店告知を出しているのは `@treca_capital` でした（store-name-b の実測）。
**支店専用の口が無い支店の告知は、ブランド全体の口が担う。**

> `trecapi_akiba`（AKIBA支店の口）は、これで登録名を失います。
> **`トレカキャピタルAKIBA店` という行が実データに無い**ので、勝手に名前を
> 作って登録することはしませんでした。行が現れたら登録します。

# 3. PR #1411 — workflow を連続で叩くときの手順

`docs/workflow-pacing.md`（新規）と `docs/assumptions.md` に1節。

```
① run が completed になるまで待つ
② **main を fetch し直して、前の run が書くはずの成果物が見えるまで待つ**
③ 見えてから次を出す。見えなければ**次を出さずに止める**
```

②を飛ばさない。「run が完了した」は待つ理由になりません——段と段のあいだに置いて
あるのは**ファイルではなく main のコミット**で、push は競合すると押し直すぶん遅れます。

roundup が 2026-09-06 に踏んだ「回収のコミットが main に見えてから起動する」と
同じ型なので、**両方をこの1本にまとめました。**
