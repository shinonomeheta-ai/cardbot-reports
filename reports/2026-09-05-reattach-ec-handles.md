## 2. 付け替え2件（PR #1296）

```
フルコンプ各店 @fullcomp_online → フルコンプ 通販
駿河屋       @surugaya_toreka → 駿河屋 通販
```

どちらも **M1g が同じチェーンとして束ねている**ので、表示の枠は変わりません。
変えたのは権限（どの行の公式Xか）だけです。付け替え先の行が台帳にあることを
確認してから行いました。

### 失う応募回（ご依頼の点）

```
公式Xと一致した応募回   993 → 993

失う  駿河屋       crnd_d8a221b77872
      駿河屋       crnd_prov_2445c541e00e
得る  駿河屋 通販    crnd_8d0b78973dfa
      駿河屋通販     crnd_1683f7050c6f
```

**差し引き0**でした。同じ根拠が、正しい行の側で数えられるようになった形です。
配布データへの影響はありません（どちらの店も配布0行）。

`フルコンプ各店` は失う応募回も得る応募回もありません（その handle の根拠を持つ
応募回が無いため）。

### 途中で分かったこと

`駿河屋 通販` と `駿河屋通販` は、**台帳では同じ1行**です
（`store_key` は `EI.norm` なので空白が落ちて `駿河屋通販` に揃う）。
M1g の `store_keys` には2つ並んでいますが、指している行は1つです。
`tenant_key` も空白を落とすので、公式Xの引きも1つの鍵に揃います。
付け替え先はその行の `canonical_name`（`駿河屋 通販`）にしました。
