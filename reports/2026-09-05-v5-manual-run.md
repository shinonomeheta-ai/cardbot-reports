### 4. 判断が要る点

1. **補充を自動で回す配線**: `official-x-ingest.yml` は手起動専用。API 経路の取り込みが実際に動いている `candidate-ai-review.yml`
   （毎朝の submit の中で根拠の投稿を lookup する step）の後に同じ補充 step を足すか。a の直し（取り込みが `media_urls` を渡す）で
   **新しく取る投稿は API 経路でも画像が入る**ので、補充が要るのは API が `includes.media` を返さなかった投稿だけになる見込み。
   次の朝の走行の要約「うち画像あり N」で API 側が画像を返しているかが分かる。それを見てから決めてよい
2. 「後」の確定率は、朝の走行（20 件/日・画像ぶんで 10〜15 件）が数日進んでから、前と同じ数え方で測る（予定どおり）
3. 手動で追加の走行を回すか（1 走行 $0.2 前後の実費・上限 $1.10）。回すなら本人承認をもらってから
