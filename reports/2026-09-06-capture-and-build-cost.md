## 3. `route:kv` の推移と、Vercel の費用

### 経路

| 枠 | 開けた | route:kv | route:render | 新しい投稿 | 告知 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 8:00（Vercel経路の前） | 30 | 0 | **30** | **0** | 0 |
| 12:23 | 440 | **438** | 2 | 1,493 | 68 |
| 14:00 | 440 | **439** | 1 | 1,471 | 55 |

`route_posts:render` は両枠とも **0**。runner の描画は今も Cloudflare に
塞がれたままで、**KV 経路が無ければ0件のまま**です。

### 読み取りの実測

1周 約25分（10かたまり）。3周/日で **約75分/日**、設計時の見込み（70分/日）どおり。

### 費用の主因は Build CPU Minutes だった

本人の請求画面で確定（9/2 $4.06・9/3 $5.27・9/5 $5.77）。
xread は Fluid Active CPU $0.07 ＋ Memory $0.05 で**問題ではありません**。

```
日ごとのデプロイ数  9/1 61 → 9/2 125 → 9/3 178 → 9/4 128 → 9/5 204
1ビルドの実測       58秒 / 71秒
直近200コミット     web/ あり 55 ／ 直下の材料あり 9 ／ どちらも無い 136（68%）
```

**`[skip ci]` は GitHub Actions を止めるだけで Vercel は止まりません。**

#1358 で `web/vercel.json` に `ignoreCommand` を入れました。実測で、直近20デプロイの
うち **10件が `CANCELED`**（docs だけの PR・その枝のプレビュー・マージコミット）。
配布データを更新する巡回は今までどおりビルドされています。

#### 途中で見つけた2つの穴

1. **`web/` だけでは足りない。** `publish.mjs` はリポジトリ直下の7ファイル
   （`store_x_accounts.json` などの許可表・`accounts.json` の収集元）を読んで
   **配る中身を変える**。直近200コミットのうち9件がこれに当たり、`web/` だけの
   判定なら**古い許可表のまま配られていました**
2. **`ignoreCommand` は `web/` の中で走る。** 最初の版を枝へ push したら、
   `web/` を変えているのにプレビューが `Canceled by Ignored Build Step` に
   なりました。`web/` の中に `web/` は無いので、**何を直してもビルドされない**
   状態です。`:/`（リポジトリ直下からの指定）に直しました

どちらも `ignore-build.test.mjs` で固定しています（材料を1つ抜くと落ちることを確認）。
